espeak-ng is used by 227 AI for offline text-to-speech. It is NOT bundled with
this project; 227 AI loads the library that ships with the device operating
system (libespeak-ng.so.1).

If your device does not already provide it, install the Debian packages
`espeak-ng` and `libespeak-ng1` (for example: `sudo apt-get install espeak-ng`).
