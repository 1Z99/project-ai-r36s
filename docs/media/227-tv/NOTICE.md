# France 24 Playback Captures

`watch.png` and `matrix.png` contain broadcast frames from public France 24
feeds, captured for 227 TV application documentation. The native app decoded
France 24 French for the watch view and four distinct language feeds (French,
English, Arabic and Spanish) for the matrix. These are PC playback screenshots,
not handheld captures, performance benchmarks or audio verification. Playback
also continued behind the opaque Settings and quality menus.

- Official broadcaster: https://www.france24.com/
- French feed: https://live.france24.com/hls/live/2037179-b/F24_FR_HI_HLS/master_5000.m3u8
- English feed: https://live.france24.com/hls/live/2037218-b/F24_EN_HI_HLS/master_5000.m3u8
- Arabic feed: https://live.france24.com/hls/live/2037222-b/F24_AR_HI_HLS/master_5000.m3u8
- Spanish feed: https://live.france24.com/hls/live/2037220-b/F24_ES_HI_HLS/master_5000.m3u8

The generated [capture record](captures.json) preserves the source and selected
playback URLs, capture timestamps, observed frame counts, source formats and
source/output hashes. The capture run used network access and real video
decoding, with null/disabled audio output and no handheld or controller access.
The website serves the resulting media locally; it does not open streams or
make external media requests. Browser and installer views are scripted interface
states with authentic station names and sample cards; nothing was installed.
