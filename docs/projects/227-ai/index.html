227 AI / Overview

227 AIOffline. On the R36S.

01 / BEFORE INSTALLINGNATIVE APP / NOT A BROWSER DEMO

A native app.
A small local model.

227 AI runs on the handheld using Python, SDL2 and a local llama.cpp engine. Conversations and settings stay in files on your SD card. The website's PC walkthrough is a separate demonstration with scripted replies and simulated microphone input.

The app includes an on-screen keyboard, saved chats, short English dictation with Whisper and selected-reply read-aloud with espeak-ng. Dictation requires a usable USB microphone; text chat does not.

Start with the tested setup.

The recorded hardware run used an R36S with a Panel 4 display and dArkOSRE build 03082026. It does not certify every R36S variant, firmware image or a fresh two-card installation.

You need internet for initial installation and about 700 MB of free SD-card space, plus separate space for any missing system dependencies. Model loading and answers can take time. A small model can be wrong; there is no live web search or speed guarantee.
